# Shadow Rival: City Hunt (Working Title)

เกมแนว **Multiplayer Action / Stealth** ที่ให้ผู้เล่น 2 คนชิงชัยกันในภารกิจลอบสังหารเป้าหมายท่ามกลางเมืองขนาดใหญ่ ทั้งสองฝ่ายจะต้องสังเกตพฤติกรรม NPC วางแผนหลบหลีกการตรวจจับ และหาจังหวะลงมือ โดยไม่เพียงแต่ต้องแข่งกับเวลาและผู้เล่นอีกคน แต่ยังต้องรับมือกับระบบ AI ตำรวจและตอบสนองต่อสถานการณ์ที่เปลี่ยนแปลงตลอดเวลา

---

## 🎮 Gameplay Overview (รูปแบบการเล่น)

การแข่งขันในแต่ละรอบจะแบ่งออกเป็น **2 ช่วงหลัก (Phases)** ที่สร้างความตึงเครียดต่อเนื่องตั้งแต่ต้นจนจบ:

### 1. Assassination Phase (ช่วงลอบสังหาร)
* ผู้เล่นทั้งสองจะเกิดในตำแหน่งที่แตกต่างกันทั่วเมือง
* ทั้งคู่จะได้รับแจ้งข้อมูลเป้าหมายเดียวกัน (Target) แต่เป้าหมายจะเดินและปะปนอยู่กับชาวบ้านทั่วไป
* ผู้เล่นต้องสะแกน สังเกตพฤติกรรม และหาทางลงมือให้เร็วและแนบเนียนที่สุดโดยไม่ให้ตำรวจรู้ตัว

### 2. Escape Phase (ช่วงหลบหนี)
* เมื่อเป้าหมายถูกสังหารสำเร็จ **เมืองจะเข้าสู่สถานะ Alert** ทันที
* **ฝ่ายสังหาร:** ยังไม่ได้รับชัยชนะทันที ต้องเอาชีวิตรอด หลบหนีการไล่ล่าของตำรวจ และเดินทางไปยัง **"พื้นที่ปลอดภัย" (Safe Zone)** เพื่อยืนยันชัยชนะ
* **ฝ่ายตามหลัง:** ยังมีโอกาสแก้ตัว! สามารถใช้จังหวะความวุ่นวายติดตาม ขัดขวาง หรือดักซุ่มผู้เล่นฝ่ายสังหารเพื่อพลิกสถานการณ์ก่อนที่อีกฝ่ายจะเข้า Safe Zone

---

## 🤖 AI System (ระบบ AI และ NPC ภายในเมือง)

สิ่งแวดล้อมภายในเมืองเต็มไปด้วย AI ที่มีพฤติกรรมแตกต่างกัน ซึ่งเป็นองค์ประกอบสำคัญในการซ่อนตัวและสร้างความท้าทาย:

* **Civilians (ชาวบ้านทั่วไป):** เดินและใช้ชีวิตตามกิจวัตรปกติ ใช้เป็นที่ซ่อนตัว (Social Stealth) เพื่อกลมกลืนกับฝูงชน
* **Target (เป้าหมายหลัก):** เดินปะปนกับชาวบ้าน มีเส้นทางเดินและพฤติกรรมเฉพาะตัวที่ผู้เล่นต้องคอยสังเกตเพื่อระบุตัวตน
* **Police (ตำรวจ):** ลาดตระเวนตามจุดต่างๆ ตอบสนองต่อพฤติกรรมผิดปกติ เช่น การวิ่งชักอาวุธ การทำร้าย NPC หรือเมื่อเมืองเข้าสู่สถานะ Alert

---

## ✨ Key Features (จุดเด่นของเกม)

* **Dual Threat Gameplay:** รับมือความท้าทายสองชั้นไปพร้อมกัน—ทั้งการชิงเชิงกับผู้เล่นจริง (PvP) และการรับมือกับ AI ที่มีปฏิกิริยาต่อการกระทำของผู้เล่น (PvE)
* **Dynamic City Alert Status:** เมืองจะเปลี่ยนสภาพแวดล้อมตามสถานการณ์ การลงมือสังหารจะเปลี่ยนโทนเกมจากการลอบเร้น (Stealth) ไปสู่การหลบหนีตื่นเต้นระทึกขวัญ (High-Octane Escape) ทันที
* **Social Stealth & Observation:** เน้นการใช้สมอง สายตา และการวางแผนมากกว่าการดวลปืนตรงๆ ชัยชนะมาจากสังเกตพฤติกรรม NPC และการเลือกจังหวะลงมือที่เหมาะสม
* **Comeback Mechanics:** ระบบไม่ได้จบลงทันทีที่เป้าหมายตาย เปิดโอกาสให้ผู้เล่นฝ่ายที่พลาดเป้าหมายแรกสามารถดักซุ่มและขัดขวางฝ่ายตรงข้ามช่วงหลบหนีเพื่อพลิกเกมได้
